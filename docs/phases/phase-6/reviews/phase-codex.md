## P4 — Phase 7 fragility

- **Dropping lifecycle fields cannot produce the accepted-config view.** The parser puts warming-only and draining-only listener configs into the same collection as active configs. A comparator that simply excludes `State`, as the design proposes for equality, can then count a warming route as active or a draining route as current. Phase 7 needs lifecycle state when deciding which configs to compare.
